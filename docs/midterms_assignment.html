Assignment #1 – About Me

Explanation/Learnings

This activity helped me visualize how Java handles memory through its stack and heap. I learned that primitives like int grade live directly on the stack, while objects like Student are stored in the heap, and references like s1, s2, s3 are just pointers on the stack pointing to those heap objects.

A key insight was realizing that s3 = s2 does not copy the object but copies the reference, so when s3.name = Ana happens, it modifies the same object s2 points to since both share that address in memory. This reinforced how OOP isn't just about writing classes but understanding how objects, state, and references actually interact.

me, it is like building with Legos: the individual pieces (primitives) are simple and self-contained, but the whole structure (object references) only works when you understand how they connect and share space in memory.

Activity #2 – Operators

Explanation/Learnings

            
class Student{

    String  name;
    int     grade;

    Student(String n, int g){
        name    = n;
        grade   = g;
    }

    void pr(){
        System.out.println(name + " " + grade);
    }

}
    

public class TestStudent {
    public static void main(String[] args) {

        Student s1 = new Student("John", 85);
        Student s2 = new Student("Maria", 90);
        Student s3 = s2;

        s1.grade = 95;
        s3.name = "Ana";

        s1.pr();
        s2.pr();
        s3.pr();
    }

}
